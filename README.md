# Digital Juanex

Grupo: 
1. Jhon Fredy Mejia
2. Juan Esteban Contreras Castellanos

Objetivo General: Desarrollar una plataforma web para la gestión y monetización de productos de streaming digitales mediante metodología scrum para usuarios y administradores

📌 Funcionalidades implementadas

🔐 Autenticación
  Registro de usuarios
  
  Inicio de sesión seguro
  
  Encriptación de contraseñas con bcrypt
  
  Control de roles (usuario / administrador)
  
🔄 Recuperación de contraseña
  Solicitud de recuperación por correo electrónico
  
  Generación de tokens únicos y seguros
  
  Expiración de tokens (1 hora)
  
  Validación de token en frontend
  
  Restablecimiento de contraseña seguro
  
  Bloqueo de reutilización de tokens
  
  Limpieza automática de tokens con cron job
  
👤 Gestión de usuario
  Visualización de perfil
  
  Actualización de datos personales
  
  Control de estado de usuario
  
🛒 Módulo de pedidos
  Creación de pedidos
  
  Gestión de estados (pendiente, aprobado, rechazado)
  
  Asociación de productos a pedidos
  
🧑‍💻 Panel administrativo
  Visualización de usuarios
  
  Gestión de pedidos
  
  Control de pagos
  
  Dashboard operativo
  
🎨 Frontend
  Interfaz en React
  
  Diseño moderno oscuro (black + red + fuchsia + purple)
  
  Rutas protegidas
  
  Experiencia de usuario optimizada
  
⚙ Backend
  Node.js + Express
  
  API REST estructurada
  
  PostgreSQL como base de datos
  
  Nodemailer para correos
  
  Cron jobs para mantenimiento automático
